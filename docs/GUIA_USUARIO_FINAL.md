# Guía de uso para Solicitantes y Junta Directiva

**Aplicación:** Flujo de Control de Gastos

**Dirigida a:** Solicitantes y miembros de Junta Directiva (JD)

**Contrato vigente:** Constitución 2.20.0

## 1. ¿Para qué sirve la aplicación?

La aplicación permite registrar solicitudes de gasto, adjuntar cotizaciones,
obtener las decisiones correspondientes y conservar el seguimiento hasta el
cierre con factura.

Cada persona ve únicamente las opciones que corresponden a sus funciones:

- un **Solicitante** puede crear solicitudes cuando tiene habilitada esa
  función, consultar su avance, atender correcciones y completar el cierre;
- un miembro de **Junta Directiva (JD)** puede revisar, aprobar, rechazar,
  devolver a revisión o votar cotizaciones cuando tiene una acción asignada;
- una misma persona puede cumplir ambos perfiles si su acceso lo permite.

Si un botón o menú no aparece, normalmente significa que la acción no está
asignada a ese usuario o que el estado actual de la solicitud no la permite.

## 2. Ingreso y seguridad de la cuenta

### Primer ingreso

1. Abre la dirección de la aplicación suministrada por la administración.
2. En **Iniciar sesión**, escribe tu correo y la contraseña temporal recibida.
3. Pulsa **Entrar**.
4. En **Crea tu contraseña**, vuelve a escribir la contraseña temporal.
5. Define y confirma una contraseña nueva de 10 a 128 caracteres.
6. Pulsa **Guardar contraseña**.

La contraseña es personal. No la compartas ni envíes cotizaciones o facturas a
través de cuentas de otras personas.

### Si olvidaste la contraseña

Solicita a la administración que envíe un nuevo enlace de restablecimiento.
Cuando llegue el correo:

1. abre el enlace más reciente;
2. escribe y confirma una contraseña nueva de 10 a 128 caracteres;
3. pulsa **Restablecer contraseña**;
4. vuelve a **Iniciar sesión** con la contraseña nueva.

El enlace es personal, funciona una sola vez y normalmente vence después de 30
minutos. Solicitar otro enlace invalida el anterior. Si aparece “el enlace no es
válido o ya venció”, pide uno nuevo.

## 3. Pantallas principales

| Pantalla | Uso principal |
| --- | --- |
| **Inicio** | Muestra lo que requiere tu atención, tus solicitudes abiertas y un resumen reciente. |
| **Solicitudes** | Permite crear, buscar y consultar solicitudes, abrir soportes y revisar el avance del flujo. |
| **Seguimiento** | Presenta la carga pendiente de los grupos y sus miembros. Es solo lectura. |
| **Facturas** | Permite consultar facturas cerradas cuando esta opción está habilitada. |
| **Configuración** | Solo aparece para personas con responsabilidades administrativas. |

En **Inicio**, el bloque **Acciones pendientes** es la referencia principal de
trabajo. Al seleccionar una acción, la aplicación vuelve a comprobar que siga
vigente antes de mostrar los controles disponibles.

En celular, la navegación aparece como una banda horizontal debajo de tu nombre:
deslízala para ver todas las opciones. Las Solicitudes se muestran como tarjetas
con el nombre de cada dato; formularios, filtros y acciones se apilan para poder
usarlos sin ampliar la pantalla. Los menús y ventanas pueden cerrarse desde su
control visible y respetan el área segura del dispositivo.

## 4. Instructivo para Solicitantes

### 4.1 Crear una solicitud sencilla

Usa este tipo cuando existe un proveedor y una cotización principal.

1. Entra a **Solicitudes**.
2. En **Registrar gasto**, selecciona **Solicitud sencilla**.
3. Completa:
   - **Título**;
   - **Área**;
   - **Categoría**;
   - **Nivel de urgencia**: Baja, Normal, Alta o Crítica;
   - **Monto (USD)**;
   - **Proveedor**;
   - **Descripción / justificación**.
4. Agrega al menos un soporte:
   - una **URL del producto o servicio**;
   - una **cotización** en PDF, JPEG, PNG o WEBP, de máximo 10 MB;
   - o ambos.
5. Revisa la información y pulsa **Crear solicitud**.

La Categoría depende del Área seleccionada. Si no aparece la categoría
correcta, consulta con la administración antes de enviar la solicitud.

La aplicación solo confirma la solicitud cuando puede iniciar el flujo con al
menos otra persona habilitada para aprobar. Si muestra un error de aprobadores o
de soporte, la solicitud nueva no queda registrada: corrige la configuración o
el archivo y vuelve a enviarla.

### 4.2 Crear una solicitud con múltiples cotizaciones

Usa este tipo cuando la decisión debe tomarse comparando varias opciones.

1. En **Registrar gasto**, selecciona **Múltiples cotizaciones**.
2. Completa Título, Área, Categoría, Nivel de urgencia y Descripción.
3. Registra por lo menos dos opciones.
4. Para cada opción completa:
   - **Proveedor**;
   - **Monto (USD)**;
   - URL o archivo de cotización obligatorio;
   - **Observaciones**, si son necesarias.
5. Usa **Agregar opción** para incluir más alternativas.
6. Revisa que cada proveedor tenga su soporte correcto.
7. Pulsa **Crear solicitud**.

La solicitud quedará en **Votación de cotizaciones**. Los participantes son
definidos al abrir la ronda y el Solicitante no vota en su propia solicitud.

### 4.3 Consultar el avance

Puedes revisar una solicitud desde **Inicio** o **Solicitudes**.

En **Solicitudes** puedes:

- buscar por ID, título o proveedor;
- filtrar por Estado, Categoría y Urgencia;
- abrir el título para ver el detalle;
- consultar cotizaciones y soportes;
- pulsar **Avance del flujo** para ver respuestas y pendientes;
- consultar la factura cuando la solicitud esté cerrada.

No es necesario actualizar la página continuamente. Después de una acción, la
aplicación recarga la información relacionada.

### 4.4 Atender una solicitud devuelta a revisión

Cuando JD selecciona **Enviar a revisión**, la solicitud cambia a **Corrección
solicitada** y aparece **Corregir y reenviar** en Inicio.

1. Abre la acción pendiente.
2. Pulsa **Abrir para corregir / reenviar**.
3. Revisa el comentario que indica qué debe corregirse.
4. Modifica los datos o soportes necesarios.
5. Pulsa **Guardar y reenviar**.

La corrección actualiza la misma solicitud y conserva su tipo original:
Sencilla continúa siendo Sencilla y Múltiples cotizaciones continúa siendo
Múltiples cotizaciones. En este último caso se abre una ronda nueva y los votos
anteriores dejan de ser vigentes.

### 4.5 Cancelar una solicitud

Cuando el estado lo permita, la fila mostrará **Cancelar solicitud**.

1. Verifica que seleccionaste la solicitud correcta.
2. Pulsa **Cancelar solicitud**.
3. Confirma la acción e indica el motivo si la aplicación lo solicita.

Una solicitud **Cancelada** no continúa el flujo ni puede cerrarse. Si el botón
no aparece, el estado o tu relación con la solicitud no permiten cancelarla.

### 4.6 Registrar la factura y cerrar

Cuando una solicitud esté **Aprobada**, el Solicitante verá **Subir factura y
cerrar** en Inicio o **Registrar factura y cerrar** en Solicitudes.

1. Abre la acción de cierre.
2. Adjunta la factura en PDF, JPEG, PNG o WEBP.
3. Agrega notas de cierre si corresponde.
4. Pulsa **Subir factura y cerrar**.

Después del cierre, la factura queda disponible en la solicitud. Si es necesario
reemplazarla, usa **Corregir factura** cuando esa opción esté disponible; la
aplicación conserva la evidencia anterior.

### 4.7 Delegar el cierre o la factura

El Solicitante puede delegar el cierre de una solicitud cuando aparezca
**Delegar cierre/factura**.

1. Abre la solicitud aprobada o su acción pendiente.
2. Pulsa **Delegar cierre/factura**.
3. Selecciona una persona activa y confirma con **Delegar**.

La delegación aplica solamente a esa solicitud. El delegado puede cargar la
factura y cerrar, pero no puede cambiar la delegación. El Solicitante puede
cambiar o revocar el delegado mientras la acción sea válida.

## 5. Instructivo para Junta Directiva (JD)

### 5.1 Localizar el trabajo pendiente

1. Entra a **Inicio**.
2. Revisa **Acciones que requieren mi atención**.
3. En **Acciones pendientes**, selecciona una solicitud.
4. Verifica su ID, urgencia, descripción, monto, proveedor, tipo de flujo y
   soportes antes de responder.

Una acción que ya atendió otra transición del flujo puede desaparecer. Si al
abrirla aparece “Ya no tienes acciones pendientes”, pulsa cerrar o regresa a
Inicio: la aplicación evitó registrar una respuesta obsoleta.

### 5.2 Aprobar, rechazar o enviar a revisión

En una acción **Responder aprobación**:

1. revisa la justificación y todos los soportes;
2. escribe un comentario cuando sea útil para dejar contexto;
3. selecciona una decisión:
   - **Aprobar**: registra conformidad y permite continuar el flujo;
   - **Rechazar**: finaliza la solicitud como rechazada;
   - **Enviar a revisión**: devuelve la solicitud al Solicitante para corregir.

**Enviar a revisión** exige un comentario de al menos 3 caracteres. El comentario
debe indicar concretamente qué información, monto, proveedor o soporte necesita
corrección. JD no edita directamente una solicitud ajena.

### 5.3 Votar una cotización

En una acción **Votar cotización**:

1. compara proveedor, monto, observaciones y soportes de todas las opciones;
2. selecciona **Votar por esta opción** en la alternativa elegida;
3. confirma que la acción se registró correctamente.

La ronda espera a todas las personas invitadas. Cuando todos votan:

- una opción con la mayor cantidad de votos, sin empate, queda seleccionada y la
  solicitud pasa a **Aprobada**;
- un empate mantiene la solicitud en **Votación de cotizaciones** hasta que un
  participante cambie su voto;
- cada participante conserva un único voto vigente.

Después de votar, la acción personal puede desaparecer aunque la ronda continúe
esperando a otros miembros.

### 5.4 Usar Seguimiento

La pantalla **Seguimiento** permite consultar:

- miembros activos por Grupo;
- Rol de cada miembro;
- cantidad de acciones pendientes por persona y Grupo;
- total de trabajo pendiente;
- búsqueda por nombre, Grupo o Rol;
- filtro de personas con pendientes.

Seguimiento es informativo. No permite reasignar Roles, aprobar, votar ni editar
solicitudes.

## 6. Estados de una solicitud

| Estado | Significado para el usuario |
| --- | --- |
| **Enviada** | La solicitud fue registrada y el sistema prepara o inicia su flujo. |
| **Pendiente de aprobación** | Espera una o más decisiones asignadas. |
| **Votación de cotizaciones** | Espera los votos de la ronda activa. |
| **Aprobada** | La decisión fue favorable; falta registrar factura y cerrar. |
| **Rechazada** | La solicitud no fue aprobada. |
| **Corrección solicitada** | El Solicitante debe modificarla y reenviarla. |
| **Cancelada** | El Solicitante o una autoridad válida detuvo el proceso. |
| **Cerrada** | Se registró la factura y terminó el expediente. |

El estado determina las acciones disponibles. Ver una solicitud no significa
necesariamente que puedas modificarla o responderla.

## 7. Correos y enlaces de acción

La aplicación puede enviar notificaciones relacionadas con acceso, aprobación,
votación, revisión o restablecimiento de contraseña.

- Para restablecer contraseña, usa solamente el enlace más reciente. Para otras
  acciones, verifica primero en **Inicio** que continúen pendientes.
- No reenvíes enlaces personales a otra persona.
- Verifica el ID, título y monto antes de confirmar una decisión.
- Si un enlace venció o la acción ya fue atendida, entra a **Inicio** para revisar
  el estado actualizado.
- La aplicación nunca solicita que envíes tu contraseña por correo.

## 8. Problemas frecuentes

### No veo “Registrar gasto”

Tu usuario no tiene habilitada la creación de solicitudes. Solicita a la
administración que revise tu acceso.

### No veo una aprobación o votación esperada

Confirma primero en **Inicio**. La acción puede haber sido completada, vencida,
reemplazada por una corrección o no haber sido asignada a tu usuario.

### La solicitud continúa en votación después de mi voto

Es normal si faltan participantes o existe empate. Tu acción personal puede
desaparecer mientras el proceso general continúa abierto.

### No puedo abrir un soporte

Comprueba que la sesión siga activa y permite la apertura de una nueva pestaña.
Si el archivo continúa sin abrir, informa el ID de la solicitud y el nombre del
archivo a la administración.

### Mi sesión terminó

Vuelve a iniciar sesión. Por seguridad, una sesión inválida, revocada o inactiva
regresa automáticamente al Login.

### El sistema rechaza el archivo

Verifica el formato real y el tamaño. Cambiar solamente la extensión del archivo
no convierte su contenido. Utiliza PDF, JPEG, PNG o WEBP según el campo.

### Guardé una corrección, pero el flujo cambió

Es el comportamiento esperado: reenviar invalida la ronda anterior y crea las
acciones vigentes para la información corregida.

## 9. Buenas prácticas

- Usa títulos que permitan reconocer el gasto fácilmente.
- Explica la necesidad y el beneficio en la justificación.
- Verifica proveedor, monto, Área y Categoría antes de enviar.
- Adjunta documentos legibles y correspondientes a la opción correcta.
- No uses urgencia **Crítica** si la situación no lo requiere.
- En JD, revisa todos los soportes antes de decidir o votar.
- Usa **Enviar a revisión** con instrucciones concretas, no como rechazo informal.
- Registra la factura tan pronto como esté disponible.
- Para solicitar soporte, proporciona el ID visible de la solicitud; nunca
  compartas tu contraseña o enlaces personales.

## 10. Resumen rápido

```text
Solicitante
Crear → Dar seguimiento → Corregir si se solicita → Registrar factura → Cerrar

Junta Directiva
Revisar pendiente → Aprobar / Rechazar / Enviar a revisión
                  → o votar una cotización cuando corresponda

Solicitud con varias cotizaciones
Crear opciones → Votan todos los invitados → Ganador único → Aprobada
```
