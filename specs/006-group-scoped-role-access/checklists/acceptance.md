# Aceptación 006

- [x] un Rol no puede pertenecer a dos Grupos.
- [x] un Usuario no puede tener dos Roles del mismo Grupo.
- [x] seleccionar Rol deriva membresía.
- [x] “Sin rol” elimina membresía de ese Grupo.
- [x] permisos directos están rechazados.
- [x] Cargo→Rol está rechazado.
- [x] Cargo no cambia permisos efectivos.
- [x] cambios UI no persisten hasta Guardar cambios.
- [x] un Usuario tiene máximo un Cargo.
