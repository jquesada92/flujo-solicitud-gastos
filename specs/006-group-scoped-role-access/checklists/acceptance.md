# Aceptación 006

- [x] un Grupo puede existir sin Roles.
- [x] un Rol puede existir sin Grupo y entonces es global.
- [x] un Rol no puede pertenecer a dos Grupos.
- [x] un Usuario no puede tener dos Roles del mismo Grupo.
- [x] un Usuario puede tener varios Roles globales ordinarios.
- [x] seleccionar Rol agrupado deriva membresía.
- [x] “Sin rol” elimina membresía de ese Grupo.
- [x] un Rol global no crea membresía.
- [x] quitar un Rol de un Grupo lo convierte en global sin borrar asignaciones.
- [x] agrupar Roles se rechaza si produciría dos Roles del mismo Grupo para un Usuario.
- [x] permisos directos están rechazados.
- [x] Cargo→Rol está rechazado.
- [x] Cargo no cambia permisos efectivos.
- [x] cambios UI no persisten hasta Guardar cambios.
- [x] un Usuario tiene máximo un Cargo.
- [x] Administrador del sistema se representa como Rol global técnico protegido.
